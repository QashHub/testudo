# Testudo – AI-Assisted Mobile Security

Testudo is an Android mobile app developed as a Curtin University
capstone project. It uses machine learning to detect and analyse
malicious apps, provide risk assessments, maintain security records,
and help users monitor threats on their device.

## Features

- AI-assisted malware detection and analysis
- Application security scanning
- Machine-learning-based risk scoring
- AI Risk Reports with threat information and recommendations
- Background scanning and real-time threat notifications
- Persistent scan history
- Threat and malware signature logging
- Quarantine records for suspicious applications
- User profile and preference management
- Cache and temporary file management
- Security status dashboard
- Room Database for persistent application and security data

## Application

The application contains six primary interfaces:

- **Home** – Security dashboard and scanning
- **User Profile** – User information and preferences
- **Cache Management** – Cache and temporary file management
- **Status** – Current application security status
- **Settings** – Customisable application preferences
- **AI Risk Report** – Malware analysis, risk scores and recommendations

## Technology Stack

- **Mobile:** Kotlin, Java, Android Studio
- **UI:** Jetpack Compose
- **Machine Learning:** Python, Jupyter Notebook
- **Database:** Room Database
- **Version Control:** Git, Bitbucket
- **Development:** Agile / Kanban

## Setup

1. Clone the repository
2. Open the project in Android Studio
3. Allow Gradle dependencies to sync
4. Select an Android emulator or connected Android device
5. Build and run the application
